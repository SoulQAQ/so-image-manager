# SoIM v0.4.0 Gallery Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an installable, Chinese, debug-signed SoIM 0.4.0 APK that requests the correct gallery permission, persistently indexes MediaStore images, and renders real images on Home, Library, Tasks, Settings, and a pushed detail screen.

**Architecture:** MediaStore remains authoritative for original images while Room v2 is the only UI index. Permission state is a small domain contract, synchronization runs as short idempotent WorkManager slices, and Paging-backed repositories feed Compose screens. This is Phase 2A only; canonical AI analysis and search stay out of scope.

**Tech Stack:** Kotlin 2.0.21, Java 17, minSdk 29, target/compileSdk 36, Compose Material 3, Room 2.6.1, Paging 3, WorkManager, Coil, coroutines, JUnit 4, AndroidX Test.

## Global Constraints

- Work only on `codex/rebuild-core`; preserve unrelated changes in `docs/项目总览.md`, top-level `h5/`, `.kotlin/`, and `.superpowers/`.
- Do not restore WebView, H5 product routes, shared credentials, fixed providers, HTTP clients, model calls, FTS, search UI, or canonical analysis in this slice.
- Use `SoIM` as the launcher and in-app product name; every visible product string is Simplified Chinese.
- Original media is read through content URIs only and is never copied, modified, moved, renamed, or deleted.
- Request only gallery read permissions: API 29-32 `READ_EXTERNAL_STORAGE`, API 33 `READ_MEDIA_IMAGES`, API 34-36 `READ_MEDIA_IMAGES` plus `READ_MEDIA_VISUAL_USER_SELECTED`.
- Keep Android system backup disabled and release unsigned. The distributable in this phase is explicitly debug-signed and named `apk/soim-v0.4.0-debug.apk`.
- Normal Gradle builds do not advance versions. Only the publish script may atomically advance `versionName`, `versionCode`, current marker, changelog, and APK artifact after all gates pass.
- Use TDD for production behavior, export every Room schema, and review every task before proceeding.
- A connected API 29+ device/emulator remains mandatory for final acceptance; lack of one must be reported, never treated as a pass.

## Final Acceptance

- A Chinese first-launch screen appears without an automatic permission prompt; tapping `授权并扫描` opens the correct system prompt.
- Granted full or partial access produces progressively visible real images, survives restart, and never modifies originals.
- Home, Library, image detail, Tasks, and Settings contain real connected behavior rather than placeholders.
- Permission denial does not loop; permanent denial routes to settings; partial access is explicit and reselectable.
- Replayed or interrupted scans do not duplicate records or lose committed progress.
- `apk/soim-v0.4.0-debug.apk`, the version source, marker, and changelog agree exactly.
