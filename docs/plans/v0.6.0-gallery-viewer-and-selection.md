# SoIM v0.6.0 图库浏览与选择体验计划

## 目标

处理 `v0.5.0` 真机测试反馈：详情页采用原生相册式沉浸浏览，并明确 ColorOS 上“选择部分照片”的替代路径。README 在本次提交中同步为当前项目架构与使用方法。

## 已实施范围

- 图片详情默认显示顶部信息和底部操作覆盖层，约 3 秒后自动收起。
- 单击图片切换覆盖层显示和隐藏；双击在适配画面与 2.5 倍缩放之间切换；双指缩放和左右切图继续保留。
- AI 描述、标签、图片基础信息和“AI 分析”只在底部覆盖层中显示，不再以抽屉遮挡图片。
- 图片切换后重新显示覆盖层，避免用户在新图片上失去返回和操作入口。

## 部分图片选择分析

Android 14+ 的 `READ_MEDIA_VISUAL_USER_SELECTED` 选择界面由系统或 OEM 提供。ColorOS 的交互不能由 SoIM 重绘；重复请求权限只能重新打开该系统界面。

可选方案：

1. 完整媒体访问后在 SoIM 内提供相册/网格多选，仅决定哪些图片显示和参与 AI；易用，但应用仍拥有完整图库访问权。
2. 使用 `ACTION_OPEN_DOCUMENT` 打开系统文件选择器，取得每张文件 URI 的持久读取授权；可避开图库权限选择页，更适合 ColorOS，但需要支持非 MediaStore URI、独立同步生命周期和多来源唯一身份。
3. Android Photo Picker；实现较轻，但设备可能仍使用 ColorOS 的同类系统选择器，不能保证改善选择体验。

本版本不把方案 2 或 1 直接并入：两者都会扩大数据模型和权限语义。下一轮应单独冻结“多来源图片导入”设计，首选方案 2，以维持最小授权。

## 非范围

- 全图库批量分析、用户修正 UI、OCR、图片裁切、移动图集和删除原图。
- 非 MediaStore URI 的正式导入实现。

## 验收

- 单击可显示/隐藏详情覆盖层，自动收起后不再遮挡看图。
- 双击可放大和还原；双指缩放、横向切图和返回不回归。
- AI 信息不再通过底部抽屉打开。
- README 描述当前 Compose、MediaStore、Room FTS4、AI 配置与发布流程。
