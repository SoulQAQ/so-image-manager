# SoIM v0.7.0 文档导入与 AI 修正计划

## 版本策略

当前发布版本为 `0.6.0`。本次包含持久 URI 导入和 AI 结果用户修正两项向下兼容的新能力，因此发布版本为 `0.7.0`；不兼容数据或 API 变更才推进主版本，纯问题修复才推进修订号。

## 详情浏览修复

- 单击图片区域切换操作层，不自动收起。
- 顶部和底部覆盖层不响应“隐藏”手势；点击分析、返回和后续操作不会收起界面。
- 双击仍切换缩放，双指缩放和左右切图保留。
- AI 描述在底部仅展示摘要；“查看完整结果”打开只读完整文本与全部标签、分类，长文本可滚动。

## ColorOS 替代选图

- 设置页新增“从文件管理器选择图片”。
- 使用 `ACTION_OPEN_DOCUMENT`、`CATEGORY_OPENABLE`、`image/*` 和多选标记，不依赖 OEM 已选照片权限界面。
- 对每个 URI 调用 `takePersistableUriPermission(READ)`；不能持久化的 URI 不导入并给出结果提示。
- 文档来源使用 `document:<authority>` volume 和稳定的 URI 哈希 identity；读取 OpenableColumns、MIME、尺寸与时间后写入既有 image 表。
- MediaStore 权限撤销、卷卸载、部分选择移除和完整校准都排除 `document:` 来源；导入后的图片由 URI 读取失败时单独标为暂不可用。
- 导入成功后立即建立基础搜索索引，支持浏览、详情和后续 AI 分析。

## AI 用户修正

- 完整结果页提供描述编辑、恢复 AI 描述、标签/分类新增和删除。
- 每个动作直接调用 `CanonicalMetadataRepository.applyCorrection`；有效投影和搜索索引在同一事务更新。
- 删除 AI 标签/分类使用 tombstone；重跑 AI 不会重新暴露用户删除值，同 normalized key 的搜索 token 继续被抑制。
- 用户新增项和描述覆盖在重跑后保留；不开放手工编辑模型 search tokens。

## 验收

- 详情单击只在图片区域切换操作层，菜单区点击不隐藏；完整 AI 文本可查看。
- 文件管理器多选导入后重启应用仍可显示，MediaStore 同步不使其消失。
- 修正描述、增删标签/分类后搜索立即反映；AI 重跑保留用户修正。
- 覆盖单元测试、Room `5→6` 迁移、Compose/AndroidTest 编译、Lint 和 Debug 构建。
