# SoIM v0.8.0 批量 AI 分析与长按多选计划

`0.8.0` 是向下兼容的功能新增，遵循语义化版本号规则递增次版本号。本文记录开发测试基线；在真机测试确认前，不创建 GitHub Release。

## 本轮范围

- 任务页提供“分析全部图库”，二次确认后为全部可用图片创建持久化任务。
- 批量任务逐张复用单图分析服务，因此严格遵守当前模型设置中的全局、供应方和模型并发/RPM/每日额度。
- 每张图片完成后立即保存 canonical 结果和搜索投影；应用或 WorkManager 中断后，已领取未完成的项回到队列。
- 配置、凭据、协议或额度受限会暂停任务，避免将整批图片误记为失败；单张不可用、网络或供应方失败会记录后继续下一张。
- 图库页长按进入多选；支持分享、从 SoIM 移除、删除原图、分析和重新分析。

## 媒体操作边界

- “从 SoIM 移除”只隐藏本地索引条目并清除其搜索投影，不改动原始文件；同步不会自动恢复该隐藏项。
- “删除原图”仅对 MediaStore 图片可用。Android 11+ 必须经过系统删除确认；确认成功后才从 SoIM 隐藏。文件管理器导入的持久 URI 不会被当作可删除的原图。
- 分享通过 Android 系统分享面板处理，并临时授予接收端读取所选 `content://` URI 的权限。

## 数据与验收

- Room 升级至 schema v7，新增批量任务与任务项；保留从 v1 到 v7 的显式迁移链。
- 验收覆盖：任务创建、批量进度、中断恢复、系统性失败暂停、本地移除不改动原图且不再搜索命中、系统分享和删除请求。
