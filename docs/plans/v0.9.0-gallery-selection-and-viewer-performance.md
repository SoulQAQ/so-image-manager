# SoIM v0.9.0 选择体验与看图性能计划

`0.9.0` 是向下兼容的功能补全：将已有的图库多选能力扩展到首页，并修复详情页图片切换与大图解码体验。本版本仅供真机测试，不创建 GitHub Release。

## 变更

- 首页瀑布流与图库网格都支持长按进入多选，操作语义一致。
- 选中标识改为高对比圆形勾选；顶部仅显示单行选中数量和取消。
- 选择操作移到底部图标加文字栏：分析、分享、从 SoIM 移除、删除原图，避免右上角图标难以分辨。
- 部分照片访问不再在所有主页面显示横幅，权限状态继续在设置页管理。
- 详情页以图片 ID 隔离 Compose 状态，避免退出后打开另一张图片时短暂显示上一张。
- 详情图按当前视口尺寸请求解码，避免打开超高分辨率原图造成主线程布局与内存抖动。
