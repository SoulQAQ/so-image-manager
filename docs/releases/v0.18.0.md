# SoIM v0.18.0

- 新增完整数据备份与合并恢复，支持 AI 历史、用户修正、供应方、协议、主题和首页配置迁移。
- 新增 OpenAI Chat Completions、Anthropic Messages 和 Gemini 协议预设，以及可选择图片的协议调试器。
- 分析任务新增 Token 日额度、网络与电量条件、执行时段、指数退避、熔断、冷却和到期自动恢复。
- 搜索新增安全组合筛选、明确中文自然语言筛选、保存搜索和动态主题。
- 首页模块支持相册、标签、分类、保存搜索与主题，并可配置排序、布局、数量和顺序。
- 设置页新增数据库、缓存与临时文件占用统计及安全清理。
- 图片详情将文件信息移动到按需展开面板，减少看图遮挡。
- 为正式签名和 GitHub Release 分发建立独立发布流程。
