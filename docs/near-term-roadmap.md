# SoIM 近期产品路线

## 图片详情体验

- 将当前常驻底部的图片元信息移出看图画面，改为原生相册式的“详细信息”入口和按需展开面板。
- 详情浏览保持沉浸式，元信息面板关闭时不遮挡图片；面板需要支持文件名、时间、尺寸、大小、图集和后续 AI 元数据。
- 在同一详情动作层逐步加入简单裁切和移动图集。
- 裁切与移动会修改 MediaStore，实施前必须补充 Android 版本权限矩阵、用户确认、冲突命名、失败回滚和原图保护策略。

该路线不属于 `0.4.1` 图库兼容补丁，进入后续迭代时再拆分详细实施计划和验收用例。

## 下一测试包的 AI 闭环

- 先完成 Phase 3 本地搜索 schema 与规模门槛，再允许真实模型请求。
- Phase 4 首选并优先验收 `openai-responses`：支持自定义 Base URL、模型 ID、密钥、图片输入、结构化结果映射和单图持久化。
- 完整自定义 JSON 协议仍属于首个 AI 测试包范围，并与预设共用安全、资源限制、并发配额和 canonical 校验。
- 首个 AI 测试包完成单图分析、结果展示和搜索命中；全图库批量处理在后续批处理阶段实现。
