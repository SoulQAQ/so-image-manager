# Debug 到正式签名迁移验收

## 固定身份

- 包名：`cn.soul2.imageai`
- 首个正式版本：`0.19.0`
- 精确标签：`v0.19.0`
- 证书：以根目录 `release-identity.properties` 为唯一公开来源。

证书指纹为空时，`v0.18.2` 必须显示“长期正式版证书尚未配置”，且不得下载或信任异签名 APK。从 `v0.19.0` 起，缺少长期 keystore 或固定指纹必须导致构建失败。

## 真机矩阵

- API 29、33、34+：验证 `0.18.1 → 0.18.2` Debug 同签名覆盖。
- 保存迁移备份后卸载 App，确认文件仍在用户选择的位置。
- 分别用错误摘要、错误包名、错误版本、错误证书和损坏 APK 验证拒绝路径。
- 下载中取消或杀进程，确认状态可恢复或可明确重试。
- 取消未知来源授权、取消系统安装器和模拟安装器异常，确认不会丢失备份和外部 APK。
- 验证 `0.18.2 → 0.19.0` 卸载重装后可恢复标注与配置，API Key 不存在于备份中。
- 验证恢复后的缺凭据供应方保持禁用，并集中提示重新填写。
- 使用同一证书验证 `0.19.0 → 0.19.1` App 内覆盖更新。

上述链路全部通过前，不删除现有 Debug 分发兜底或仓库历史 APK。
